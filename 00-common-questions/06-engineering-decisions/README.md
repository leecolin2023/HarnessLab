# 06 · 工程决策｜常见问题

对应研究：[HarnessLab / 06-engineering-decisions](../../06-engineering-decisions/)。

## 初始候选题单

- 如何判断一项能力应该自研、复用、薄适配还是暂缓？
- 为什么技术方案选型不能只看 Demo？验证成本、维护成本怎样量化？
- 外部 Provider 已提供 Office 或 RAG 能力时，自己还应保留哪些控制层？
- 如何设计可升级的插件边界，减少对开源框架 Fork 的侵入？
- 线上 Agent 出现错误时，怎样借助日志、Trace、复现、版本和回归测试定位问题？
- 一个工程决策记录至少要说明哪些替代方案、约束、证据和重新评估条件？

讨论中区分“个人偏好”和“已被验证的工程选择”；正式决策沉淀到 [06-engineering-decisions](../../06-engineering-decisions/)。
