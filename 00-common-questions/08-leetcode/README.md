# 08 · LeetCode 算法与数据结构

**定位：** 面试算法题的思路训练、代码实现、复杂度证明与复盘。避免只保存可运行答案、不解释为什么这样做。

## 推荐题型路线（候选题，尚未完成）

| 题型 | 典型问题与可选练习 |
| --- | --- |
| 数组与哈希 | Two Sum（1）：哈希表何时优于双层遍历？ |
| 双指针与滑动窗口 | Longest Substring Without Repeating Characters（3）：窗口不变量是什么？ |
| 栈与队列 | Valid Parentheses（20）：如何选择数据结构？ |
| 二分查找 | Binary Search（704）：区间开闭与循环终止条件如何证明？ |
| 链表 | Reverse Linked List（206）：指针更新顺序为什么重要？ |
| 树与图 | Number of Islands（200）：DFS / BFS 的复杂度怎样计算？ |
| 回溯与搜索 | Subsets（78）：如何避免状态污染或重复结果？ |
| 动态规划 | Climbing Stairs（70）：状态定义与转移怎样推导？ |

## 每题至少沉淀

1. 题意、输入约束与边界样例
2. 朴素思路、瓶颈、优化过程（而非只记最优解）
3. 核心不变量 / 正确性解释、时间与空间复杂度
4. 可运行实现（按需 Python、Java）、测试样例和易错点
5. 下次复习时要检查的追问与变式

按题目 ID 命名，例如 `0001-two-sum.md`。复制 [SOLUTION_TEMPLATE.md](./SOLUTION_TEMPLATE.md) 创建新题；题型变多后再按主题划分目录，不提前建设大量空文件夹。
