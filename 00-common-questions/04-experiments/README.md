# 04 · 实验与评测｜常见问题

对应研究：[HarnessLab / 04-experiments](../../04-experiments/)。

## 初始候选题单

- 怎样证明一个 Agent “真的会做事”，而不仅是能生成看似合理的回答？
- 对两个 Harness 做公平比较，应控制哪些变量（模型、工具、任务、预算、环境等）？
- Agent 完成率、有效任务成本、Token 消耗、人工介入次数如何定义并统计？
- 对长程任务如何测试状态恢复、幂等、部分失败和结果交付？
- 如何设计可复现、避免数据泄漏的评测集？怎样分析失败样本？
- 当 AI 写代码、写测试、做审查时，怎样降低同源错误带来的虚假安全感？

实验结果和计划必须分开标注；真实实验记录留在 [04-experiments](../../04-experiments/)，本处保留问题、口头解释与追问。
