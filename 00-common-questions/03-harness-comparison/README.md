# 03 · Harness 横向比较｜常见问题

对应研究：[HarnessLab / 03-harness-comparison](../../03-harness-comparison/)。

## 初始候选题单

- Agent Framework、Agent Runtime、Harness 与 Agent 产品分别指什么？边界如何划分？
- Claude Code、Codex、OpenCode、Pi 和 DeepSeek Harness 的架构差异如何分析，而不是只比较功能表？
- 为什么同一个模型在不同 Harness 上，工具调用效果、Token 成本与完成率可能不同？
- 如何区分“模型能力差异”和“提示词、上下文、工具设计、重试策略”造成的差异？
- 企业 Agent 需要专用 Workflow 还是通用 Harness？什么场景适合组合使用？
- 更换底层 Harness 时，哪些接口、测试与业务需求应当保持稳定？

对比时写清**框架版本、相同测试条件、已证实事实与个人推断**。可回链 [对比研究](../../03-harness-comparison/) 和 [评测实验](../../04-experiments/)。
