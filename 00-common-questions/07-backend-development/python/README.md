# 后端开发 · Python

## 初始候选题单

### 语言与运行时

- Python 可变对象、浅拷贝与深拷贝的区别是什么？有什么常见坑？
- 迭代器、生成器、装饰器和上下文管理器怎样工作？
- CPython 的 GIL 是什么？线程、进程、协程如何选择？

### Web 与并发

- WSGI 与 ASGI 有何区别？FastAPI 的 async 接口何时有价值、何时反而阻塞？
- asyncio 事件循环如何调度协程？阻塞 I/O、CPU 密集任务怎样处理？
- FastAPI 的依赖注入、请求参数校验、异常处理与生命周期如何组织？
- 在 Web 服务中如何管理数据库连接、Session、事务与后台任务？

### 工程实践

- Python 项目如何组织依赖、虚拟环境、打包与部署？
- 怎样测试异步 API、外部服务失败以及数据库事务边界？
- 生产服务如何配置进程数、并发和日志，避免“能跑但不可靠”？

对 HTTP、数据库 ACID 等基础原理，请先参考 [通用基础](../general/)。
