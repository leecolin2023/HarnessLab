# 后端开发 · 通用基础

## 初始候选题单

### 网络与 API

- 一次 HTTP 请求从客户端到服务端经历什么？DNS、TCP、TLS、反向代理分别做什么？
- GET / POST / PUT / PATCH 如何区分？HTTP 幂等性与业务幂等性有什么不同？
- 连接超时、读取超时、重试、熔断与限流分别解决什么问题？

### 数据库与缓存

- 数据库索引为什么能加快查询？组合索引什么时候失效？
- 事务 ACID、隔离级别、MVCC、幻读之间是什么关系？
- 缓存穿透、击穿、雪崩如何区分？缓存与数据库怎样保持合理一致性？

### 并发与分布式

- 乐观锁、悲观锁、分布式锁各有什么适用边界？
- 消息队列如何处理重复投递、消费失败和顺序问题？
- 服务如何实现可观测性、故障定位、可靠发布和回滚？
- 如何设计一个支持限流、权限校验和审计的 API 服务？
