# 05 · 企业 Agent｜常见问题

对应研究：[HarnessLab / 05-enterprise-agent](../../05-enterprise-agent/)。

## 初始候选题单

- 企业为什么需要 Agent？哪些场景用搜索、RAG 或普通工作流就足够？
- RAG 的切分、召回、重排、引用和答案验证如何构成可靠检索链？
- 数百份银行制度如何处理版本、效力、条款级定位、跨制度冲突与权限？
- 离线、无公网环境部署 Agent 时，依赖、模型、数据、升级分别有哪些限制？
- Office 文件的读取、定位、修改、格式保真和结果校验为什么不能只靠文本生成？
- 企业内网系统接入时，身份、授权、审计、人工确认与最小权限如何设计？
- 如何区分银行领域 Skill、通用工具、确定性规则引擎与外部业务系统职责？
