# HarnessLab

**企业 AI 平台与 Agent 工程实验室**

目标：研究从零搭建企业 Agent 技术团队所需要的核心工程能力。

## 学习材料归档

由 ingest2md 采集并经过 Refinement、Deep Read 或 Learning 处理的材料统一归档到 [materials/](./materials/README.md)，按 RAG、模型平台、Agent、企业 AI 应用和 AI 求职分类。该目录与正式研究文章区分，保留原始来源追溯。

## 研究方向

- Model Platform：推理服务、模型网关、鉴权与性能。
- Agent Runtime：Agent Loop、工具、上下文与会话恢复。
- Harnesses：DeepSeek Harness、Pi、Codex 等实现的源码研究与对比。
- Agent Capabilities：MCP、Skills、RAG、Office 和企业系统集成。
- Enterprise Platform：任务管理、权限、服务化与部署。
- AgentOps：评测、可观测性、可靠性和安全。

## 建设原则

从实际问题出发，理解机制，验证实现，再形成工程决策。逐项建立有内容的目录，不预建空目录。

旧版资料保存在 archive/main-2026-10-21 和 archive/pre-rebuild-2026-10-21 分支。
