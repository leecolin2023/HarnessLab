# 07 · 企业级大模型服务平台

本目录服务于**企业模型服务开发与治理**，而非自研推理引擎、重复搭建业务 Agent。业务研发团队消费模型 API，模型平台团队保证资源、服务接口、安全与可靠性；平台组件优先复用采购产品。

| 核心能力 | 要解决的工作问题 | 证据 |
| --- | --- | --- |
| 算力资源管理 | NPU/GPU/CPU 资源怎样分配、监控与容量评估？ | 使用量及配置、资源变化前后对照 |
| 模型部署发布 | OCR/LLM 如何加载、发布、升级和回滚？ | 部署过程、模型及版本、接口验收 |
| API 服务治理 | SK 鉴权、访问权限、路由、限流、审计各负责什么？ | 接口测试与错误响应 |
| 性能与质量 | 压测如何得出成功吞吐、P95、容量上限？ | CSV 结果、监控与故障归因 |
| Agent 平台集成 | 通用模型服务与智能体工具/知识库职责边界在哪里？ | 兼容性验证和应用级回归 |

## 先研究三项稳定能力

1. **服务交付**：资源确认、模型配置、Docker、模型版本、就绪检查、回滚。
2. **服务治理**：统一接口、SK 身份认证、鉴权与授权边界、调用路由、审计。
3. **生产保障**：性能压测、容量测算、错误码、异常处理、升级回归。
